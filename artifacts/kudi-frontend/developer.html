Quick start

Create a trading transaction from your own platform:

curl -X POST https://your-api.example.com/v1/transactions \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Order #4821",
    "amount": 4820,
    "currency": "EUR",
    "buyer_email": "buyer@example.com",
    "seller_email": "seller@example.com",
    "release_conditions": "After the buyer confirms the agreed conditions"
  }'

Core endpoints

POST/v1/transactionsCreate a trading transaction
POST/v1/transactions/:id/fundFund a trading transaction
POST/v1/transactions/:id/releaseRelease funds to seller
GET/v1/transactions/:idRetrieve transaction status
POST/v1/disputesOpen a dispute on a transaction
DEL/v1/api-keys/:idRevoke an API key
