# DOCUMENTATION VIDEO LIBRARY
 
Do **NOT** redesign the Documentation Center.
 
Do **NOT** remove any existing functionality.
 
Extend the Documentation Center to support both **uploaded videos** and **embedded videos**.
  
# 16. Video Support
 
Each documentation article may contain one or more videos.
 
Support two video types:
 
### Uploaded Videos
 
Allow Admin to upload:
 
 
- MP4
 
- WebM
 
- MOV
 
- AVI (optional)
 
- MKV (optional)
 

 
Videos should be stored with the documentation and streamed directly from the platform.
  
### Embedded Videos
 
Allow embedding from supported platforms.
 
Examples:
 
 
- YouTube
 
- Vimeo
 
- Loom
 
- Wistia
 
- Microsoft Stream
 

 
The Admin only pastes the video URL.
 
The system automatically embeds the video player.
  
# 17. Video Fields
 
Each video should support:
 
 
- Video Title
 
- Video Description
 
- Video Type 
 
  - Uploaded
 
  - Embedded
 

 
 
- Upload File
 
- Embed URL
 
- Thumbnail Image
 
- Duration (optional)
 
- Display Order
 

  
# 18. Video Gallery
 
Documentation pages may contain multiple videos.
 
Display:
 
 
- Featured Video
 
- Video Gallery
 
- Playlist View (optional)
 

 
Videos should appear within the documentation page without leaving the website.
  
# 19. Admin Video Management
 
Within the Documentation CMS, Admin can:
 
 
- Upload videos
 
- Embed external videos
 
- Edit video details
 
- Replace videos
 
- Delete videos
 
- Reorder videos
 
- Change thumbnails
 
- Set Featured Video
 

 
Everything should be manageable without editing code.
  
# 20. Video Player
 
Uploaded videos should include:
 
 
- Play
 
- Pause
 
- Seek
 
- Fullscreen
 
- Volume Control
 
- Playback Speed
 
- Picture-in-Picture (where supported)
 

 
Embedded videos should use the provider's official embedded player.
  
# 21. Documentation Layout
 
A documentation page may contain:
 
 
- Featured Image
 
- Rich HTML Content
 
- Image Gallery
 
- Video Gallery
 
- Embedded Videos
 
- Attachments
 
- Download Files
 
- Related Documents
 

 
Content should flow naturally without redesigning the page.
